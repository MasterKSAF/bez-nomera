# Доказательства выбранного E27

- SELECTED.json — публичное извлечение из зафиксированного выбора модели: FP32, 4 обработчика, batch32, рецепт поиска, фактические метрики и SHA исходных отчётов. Исторические статусы подготовки комплекта не включены.
- control77/ — исходные новые GPU-векторы, ответы и официальные метрики 77/324; calibration73/ — аналогичный комплект 73/612. CSV ответов сериализованы из сохранённых решений уже выполненной приёмки. source-manifest.json отмечает производные файлы и SHA источников.
- acceptance/ — строгая CPU-проверка новых GPU-векторов: cal/control × batch/single. Совпали top10, принятые top1, отказы и официальные метрики; максимальное отклонение компонента вектора 2.69e-6 при допуске 1e-5. Порог повторно не подбирался.
- gpu/ — выбранный реальный замер NVIDIA A10 и парный baseline, фиксация выбора, получение векторов без разметки. Медиана B1 34.902914 мс, P95 39.302236 мс, batch32 119.547023 фото/с. Включены чтение/decode/bbox/preprocessing/forward/нормализация/переносы; поиск, rerank и HTTP не включены. Это не замер на конкурсной A5000. Сохранены все исходные отсчёты времени; гипотетические конкурсные баллы исключены.
- recipe/ — публичные извлечения из зафиксированных решений без личных путей. Каждое содержит SHA неизменённого исходного документа.
- historical-study/STUDY_RESULT.json — публичное извлечение из предыдущей CPU-проверки постобработки. Сохранены рецепт, SHA источников и реальные метрики до/после; внутренние целевые показатели и статусы подготовки исключены.

Качество control77: mAP@10 82.139284%; Rank-1 82.258065%; Rank-5 93.548387%; F1 90.265487%; TNR 100% (15/15). Контроль исторический, не независимый. Получение векторов измерено на GPU; полная постобработка проверена на CPU по этим векторам. Эти материалы сами по себе не объявляют новый API/Docker принятым.

Публичные извлечения явно отмечены полем derived_public_projection и содержат SHA оригинала. Они не являются побайтовыми оригиналами. SOURCE_MANIFEST.json содержит SHA всех включённых файлов и SHA исходных отчётов. Остальные файлы сохранены без изменений.
