# Материалы E27

- [Прототип](prototype/): видеодемонстрация, описание видео и инструкция Docker-запуска.
- [Документация](documentation/Инструкция.pdf): инструкция пользователя в PDF.
- [Доказательства](evidence/README.md): отчёты GPU, калибровки, контроля и исходные результаты проверки.
- [Обучение](training/README.md): служебные CSV, признаки учителя и их контрольные суммы для повторения обучения.
- [Метаданные модели](model/): конфигурация, калибровка, протокол и лицензия DINOv3.

Файлы модели с checkpoint доступны в [папке Яндекс Диска](https://disk.yandex.ru/d/rTiMM9k2yFVg7A): «Сопроводительная документация» → «Модель_E27». Runtime-веса `model.pth` в Git не включены. Импорт выполняется по инструкции корневого README.

Исторические материалы сохранены побайтово. Их состав и SHA-256 перечислены в [SHA256.json](SHA256.json). Рабочие исходники и все эти материалы также входят в корневой `SOURCE_SHA256.json`.
