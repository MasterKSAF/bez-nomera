# Дополнительные данные для повторения обучения

Для запуска готового E27 эта папка не нужна.

`teacher-train-cache/` содержит признаки учителя только для 6804 обучающих кадров. Скопируйте эту папку в `training/assets/teacher-train-cache/`. Исходные JPEG/PNG берутся из датасета организаторов. Начальные DINOv3-веса загружает `training/fetch_pretrained.py` по закреплённым revision и SHA-256; это отдельный этап подготовки, не инференс.

Профиль, команды, разбиения и журналы завершённого обучения находятся в `training/README.md` репозитория. E27 использует без изменения веса выбранной 14-й эпохи стенда 5; новое обучение для E27 не выполнялось.
